# 一瞬迷思

世俗眼中，决定人生的重要特质，譬如上课是否保持专心，危机时刻临危不乱，是否恪守规矩，其实是基因表达的结果。

比方说一个学生在重大考试的时候心神不安，紧张到拿不稳笔。这种学生会被旁人打上心里脆弱的标签。然而，有研究表明关键时候发挥失常的学生有一个同样类型的单个基因，叫做[COMT基因](https://zhida.zhihu.com/search?content_id=736000461&content_type=Answer&match_order=1&q=COMT基因&zhida_source=entity)。在关键时刻下掉链子就是该基因在一系列复杂的化合作用下外显的结果。

有人对新知识轻而易举的理解吸收；有人看见数字头晕脑胀；有人在人生的重大时刻发挥超频；有人在社交场所八面玲珑，这些看似偶然的结果其实是生理上化合物和激素的相互作用的必然结果，不为个人的意志所转移。

我认为基因决定论比出生决定论更加令人绝望，因为基因不是通过后天努力可以修改的，甚至大部分人无法意识到这点，哀叹自己不够努力，殊不知有人天生喜爱竞争，精力旺盛，擅长创新，热衷社交，这些幸运儿们的基因表达与这个社会的成功标准所契合。而普通人，或说缺少相关基因的人想达到同样标准需要付出千百倍的努力。但是他们不会意识到生理层面的问题，而是一味的慕强或者是苛责自己不努力。这难道不算一种宿命论吗？
